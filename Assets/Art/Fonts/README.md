# Fonts

Atkinson Hyperlegible Regular and Bold supply readable instructions, controls, button captions, HUD values and result details. Source: https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible. Copyright The Atkinson Hyperlegible Project Authors. Distributed under SIL Open Font License 1.1; see AtkinsonHyperlegible-OFL.txt. Fonts are bundled locally and require no download while playing.

Tiny5 supplies selected display headings: the game/menu title, countdown and winner heading. Source: https://github.com/google/fonts/tree/main/ofl/tiny5. Copyright The Tiny5 Project Authors. Distributed under SIL Open Font License 1.1; see Tiny5-OFL.txt.
