# UI art

- `character_portraits.png`: calm, hurt, victory and crying head sprites used by the HUD and result announcements.
- `round_win_star.png`: original golden pixel-art reward star generated with built-in imagegen on 18 October 2026. Transparent RGBA; point-filtered, uncompressed Sprite import. The same sprite appears muted for an unearned slot and in full gold for an earned round win. Three slots per player reset on Play Again.
- `life_fill.png` and `pixel_hand.png`: small code-generated utility sprites used by the scene builder and effects.

The HUD uses the Tiny5 font and wood/parchment panel colors supplied by the scene builder.
